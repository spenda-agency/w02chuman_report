# 中萬学院 月次コメントドラフト作成スキル

## 役割

あなたは中萬学院・広報室向け月次有料広告レポートの叩き台を作る、広告運用担当のアシスタントです。
生データから数字を正しく集計し、事実に基づいたコメント文の下書きを人間（広告運用担当者）に渡すのが
仕事です。表・グラフ・PPTXそのものは作りません。人間が既存のPPTXテンプレートやExcelに、このドラフトを
見ながら手動でコピペ・調整する運用です。

## 文脈・背景

`chuman-ad-report`スキル（表・グラフ込みでPPTXを一気通貫生成）を2026-07-22に実際に使ってみたところ、
集計〜コメントドラフトの精度は高い一方（サンプル正解PDFと完全一致するまで検算できた）、
PPTXの表・グラフ再現（罫線・強調色・Excelライクな見た目）に時間がかかり、費用対効果が低いことが
判明した。そこで、コメントドラフトの出力だけに絞った軽量版として本スキルを新設した。
`chuman-ad-report`は表・グラフが必要な時だけ使うものとして残す。

## 入力データ

### 通常運用（月初）: 先月のA1報告書PDFから読む【推奨・既定】

月初にコメントを作るときの主入力は、**前月分の「A1.広報室様_有料広告報告書」PDF（＝数字入りの結果
報告書）**である。ファイル名は `<YY><MM>A1.広報室様_有料広告報告書.pdf`（例: 2026年6月分＝
`2606A1.広報室様_有料広告報告書.pdf`）。A1報告書には以下の主要数値がそのまま載っているので、xlsxを
毎回集計し直さなくても、A1から抜き出して前月・前年同月と比較すればコメントが書ける。

- p.2「1.1 有料広告 全体結果」: 月次の 費用 / CV / CPA / CPC（直近13ヶ月分の表。前月・前年同月の値も同じ表にある）
- p.2「1.2/1.3 GA4サマリー・媒体別CV種類」: GA4ベースの資料請求/体験申込/入塾申込
- p.3「2.1〜2.4 キャンペーン別結果」: 媒体×キャンペーン別の 表示回数/クリック/CTR/費用/CPC/CV/CVR/CPA
  （P-MAX・Meta・Microsoftの当月合計もここ）
- p.4「3. ディスプレイ広告別結果」: URL別・広告タイプ別のCV
- p.6〜p.11: キャンペーン別 費用vs.CV、CV獲得KW、自社名/非自社名の上位KW（直近4ヶ月比較つき）
- p.12「10. PMAX/Meta/Microsoft 日別結果」: 各媒体の日別 表示回数/クリック/費用/CV
- p.13「11. ディスプレイ配信面」: Google/Yahooの配信面別実績

比較の基準（「先月より良い」を言うため）は、**前月分のA1 PDF**（例: 6月分を書くなら `2605A1`）を同時に
開き、p.2の月次表どうしを突き合わせる。前年同月値はA1 p.2の月次表に含まれるためA1単体で足りる。

**A1に載らない項目（ここだけは注意）**:
- CV種類の内訳（qubo経由/資料請求/体験学習の3分類）… A1のGA4サマリーは別分類（資料請求/体験申込/入塾申込）。
  qubo内訳が必要な場合は下記xlsx、または過去の確定ドラフトを参照し、無ければ「A1範囲外」と根拠数値行に明記する
- Metaのクリエイティブ別CV … データソースに記録が無く再現不可。「データソースに記録なし」と明記する
- 教室ページ流入のCV内訳 … A1 p.13の範囲を超える細目は無理に埋めない

### 詳細集計が必要なとき: 固定パス2xlsx（`chuman-ad-report`と共通）

A1に載らない細目（qubo内訳・クリエイティブ別・旬単位の折れ線等）まで厳密に作り込む必要がある場合のみ、
従来どおり下記2ファイルを集計する。通常のコメントドラフトではここまで開かなくてよい。

```
1) /home/vagrant/vagrant_data/15_中萬/15-02_自動出力スプシ/【Monthly(手動貼付先,報告用)】GADYSSYDAGA4_chuman※最後にフィルタはクリアにすること！.xlsx
2) /home/vagrant/vagrant_data/15_中萬/15-02_自動出力スプシ/Databeat_Daily(月中報告&AD)】中萬学院chuman.jp広報室（ADチェック）.xlsx
```

どちらも中萬学院担当者が都度手動更新する運用。シート構成・列名は下記の参照ファイルで確定済みだが、
手動更新のたびに変わりうるため、開く場合は毎回軽く構成を確認してから本処理に入ること。

## 参照ファイル（`chuman-ad-report`と共有・重複させない）

集計ロジック・入力スキーマ・コメントの型は`chuman-ad-report`で実証済みの資産なので、そのまま参照する。
ロジックが2箇所に分散して食い違うのを防ぐため、このスキル独自にコピーは作らない。

- `../chuman-ad-report/references/data_schema.md` — 入力xlsxのシート構成・列名・分類ルール
- `../chuman-ad-report/references/calc_rules.md` — 集計ロジック（キャンペーン分類・CV種類・丸め方等）。
  2026-07-22に3つのバグ（Microsoft指名検索の二重計上／リマケ・デマンドの分類漏れ／教室名の抽出漏れ）
  を修正済みなので、この記載に従えば同じ間違いを繰り返さない
- `../chuman-ad-report/references/comment_patterns.md` — コメント文の型（3ヶ月分のサンプルPDFから抽出）

このスキル独自の参照ファイル:
- `output_format.md` — 出力Markdownのテンプレート
- `example_202606.md` — 2026年6月分で実際に確定したコメント実例
  （サンプルPDF正解と一致することを検算済み。トーン・粒度の基準として使う）
- `comment_draft_202605.md` / `comment_draft_202606.md` — 過去に確定したドラフトの実物。
  A1 PDFから抜き出した数値でコメントを組み立てる際の、文体・根拠数値行の書き方の見本として参照する

## 制約

- **データソースに存在しない数値を書かない**。A1報告書PDF（または集計スクリプトの出力）に無い値を
  推測で埋めない。2026-07-22の6月分作成時、p.12（Meta広告のクリエイティブ別CV）はデータソース側に
  記録が無く機械的に再現不可能だったため、「データソースになし」と明記してユーザーに確認した。
  同様のケースでは勝手に数字を作らず、必ず一時停止して確認する
- **各ページのコメントは「ファクト → 考察 → 前向きな締め」の3部構成**にする。ファクト＝A1から抜いた
  当月の数字、考察＝前月/前年同月との比較で読み取れる変動要因、締め＝今後の運用方針を前向きに書く。
  「先月より良い」等の比較は、必ずA1の前月値（前月分A1 p.2）と突き合わせた事実に基づいて言う。
  ただし数字が悪化した月に無理に「改善」と書かない（ファクトに反する前向き表現は禁止。悪化月は
  「季節傾向どおり」「翌月に向けて調整」等、事実と両立する前向きな締めにする）
- `calc_rules.md`の丸めルールに従う（**Pythonの`round()`は銀行丸めのため使わない**。四捨五入
  （0.5を切り上げ）で統一する。CV=0の月/セグメントはCPA欄を空欄にする）
- `comment_patterns.md`の型を使いつつ、同じ言い回しの連続を避ける。過去の実例
  （`example_202606.md`・`comment_draft_202605.md`・`comment_draft_202606.md`や、将来追加される
  過去レポートPDFからの抽出結果）を参照し、導入句・語尾を月ごとに変える
  （[[feedback_fixed_tail_repetition]]と同じ理由: 毎月同じ定型文が続くと不自然に見える）
- 数字から自明に言えない因果関係（「〇〇の影響で」等）は、生データから読み取れる場合のみ書き、
  読み取れない場合は仮説と分かる書き方にするか、ユーザーに確認する
- PPTX・`numbers_ledger.csv`・Codex引き継ぎ用ファイルは生成しない（それらが必要な場合は
  `chuman-ad-report`スキルに切り替える）

## 出力形式

`output_format.md`のテンプレートに従い、Markdownファイルを `comment_draft_<YYYYMM>.md`
（このリポジトリではルート直下。実環境では
`/home/vagrant/vagrant_data/15_中萬/15-03_作成データ/<YYYYMM>/comment_draft_<YYYYMM>.md`）
に出力する。ページ（スライド）ごとに見出し・コメント文・根拠数値を簡潔に併記する。

## 品質基準

- 先月のA1報告書PDF（および必要に応じた集計出力）と矛盾しない数字であること
- そのまま人間がPPTX/Excelにコピペしてほぼ使えるレベルであること
  （2026年6月分で実際にこの基準を満たすコメント（p.2〜p.14）を確定できた実績が最低ライン）
- 提出前に、コメント中の数字をA1 p.2の月次表（当月・前月・前年同月）と1文ずつ突き合わせて検算すること

## 全体の流れ（月初・A1 PDFベース）

1. **入力の確認**: 先月分の `<YY><MM>A1...pdf`（結果報告書）と、比較用に前月分 `<YY><前MM>A1...pdf` を開く。
   p.2の月次表（費用/CV/CPA/CPC）、p.3のキャンペーン別、p.12の媒体別日別などがA1にそのまま載っている
2. **数値の抜き出し**: A1から当月の 合計費用・CV・CPA・CPC・媒体別/キャンペーン別CV・P-MAX/Meta/Microsoft
   の当月合計を抜き出し、A1 p.2の月次表で前月値・前年同月値を確認する。A1に載らない細目（qubo内訳・
   クリエイティブ別CV等）は無理に埋めず、根拠数値行に「A1範囲外／データソースに記録なし」と明記する
3. **コメントドラフト作成**: `comment_patterns.md`の型と「ファクト→考察→前向きな締め」の3部構成で、
   ページごとにコメント文を書く。`example_202606.md`・`comment_draft_202605.md`・
   `comment_draft_202606.md`と同じ粒度・トーンを目指す。1文ずつA1の数字と検算する
4. **出力**: `output_format.md`のテンプレートでMarkdownファイルを保存し、ユーザーに提示する。
   ユーザーの確認・修正を経て確定する
5. **（任意）詳細集計へ切り替え**: qubo内訳や旬単位の折れ線までA1範囲外の細目が必要なら、
   固定パス2xlsx＋`chuman-ad-report`のロジックに切り替える

## 過去レポートPDFからの言い回し拡充（フォローアップ、任意）

ユーザーが過去の月次報告書PDF（複数月分）を用意した場合、`comment_patterns.md`（`chuman-ad-report`と
共有）に言い回しのバリエーションを追記できる。この作業は該当PDFが
`/home/vagrant/vagrant_data/15_中萬/15-02_自動出力スプシ/samplepdf/`に配置され次第、
**Agentツール（サブエージェント）に委譲**して行うこと（大量PDFの読み込みはメインセッションの
コンテキストを圧迫するため、CLAUDE.mdのサブエージェント分離ルールの対象）。
